# ピンポンカット

卓球の試合動画から、ラリーの場面だけをつないだ動画を作るブラウザツール。サーバーなし・動画は端末から出ない・無料・登録不要。

## 使い方
1. ページを開いて動画を選ぶ
2. 「完全自動」にチェックがあれば、打球音からラリーを自動で見つけて書き出しまで進む
   - 違う所は手で直せる：ラリー中だけボタンを押す（押しっぱなし／タップ切替）、バーのドラッグ、一覧の ✕
   - 「見つける量」（少なめ／ふつう／多め）を変えるとすぐ判定し直す。「取り消す」で前の印に戻る
3. 「書き出す」→ 保存（スマホは「写真に保存・共有」）

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 画面と操作（1️⃣ 動画を選ぶ → 2️⃣ 印をつける → 3️⃣ 書き出す の順） |
| `detect.js` | ラリーの自動判定（音）。自動判定を使うときだけ読み込む |
| `export.js` | 高速書き出し。書き出しを押したときだけ読み込む |
| `vendor/mediabunny-1.61.6.min.js` | MP4 の分解・組み立て部品（MPL-2.0, `vendor/mediabunny-LICENSE.txt`） |
| `privacy.html` | プライバシーポリシー |

## 書き出しのしくみ
1. **高速方式（通常）**：WebCodecs で必要なコマだけ読み取り→作り直し→MP4 に組み立て。再生しないので速い（60秒の動画で数秒）
   - 音は作り直さず元の音のかけらを並べる。区間の境目は音のかけらにそろえる → 音ズレなし
   - 映像の時刻は等間隔の格子に載せる（継ぎ目に短いコマを作らない）
   - 区間ごとに読み取り器を作り直す
   - 失敗時は診断文字列（どの段階・何本目・形式）をコンソールとエラー文に出す
2. **控え**：高速方式が使えないブラウザでは、再生しながら MediaRecorder で録画（実時間ぶんかかる）

## 自動判定のしくみ（`detect.js`）
映像は見ず、音だけで判定する。打球音は「短くて鋭い音が 1 秒前後の間隔で続く」ので、その並びをラリーとみなす。
1. 音を読み取り、低い音（声・足音）を弱めて 5 ミリ秒ごとの強さにする
2. 鋭く立ち上がってすぐ消える山を打球音の候補にする（長く続く声・歓声は落ちる）
3. いちばん大きい部類の音よりずっと小さい候補（となりの台など）を外す
4. 間隔が 1.5 秒以内の候補をまとめ、4 打以上続いたものをラリーにする（前 0.7 秒・後 0.3 秒を足す）

基準の数値は `detect.js` 先頭の `PRESETS` にまとめてある。

音の読み取りは 3 段がまえ：① WebCodecs で少しずつ読む（Chrome など）→ ② AAC を約 20 秒ずつの小さなファイル（ADTS）に分けてブラウザ標準の機能で読む（WebCodecs で音を読めない Safari など）→ ③ 丸ごと読む（600MB まで）。②は Node 上で ffmpeg に読ませて①と同じ結果になることを確認済み。Safari の実機では未確認。

**判定の記録**：自動判定のあと「判定の記録を保存」で `pinponcut-kiroku.json` ができる。中身は 5 ミリ秒ごとの音の大きさ（3 つの帯）・自動で見つけた区間・いまの印。印を手で直してから保存すれば、それが正解になり、基準の見直しに使える。動画や音そのものは入らない。
- **確認できているのは合成した検証用の音だけ**（打球音・声・足音・単発の音・となりの台を混ぜたもの。8本中8本、ずれ 0.3〜0.7 秒＝足した余白ぶん）。実際の試合動画での正解率は未計測
- 苦手なはずのもの：音のない動画、となりの台が同じくらい大きい会場、サーブ前に球を台でつく音、BGM の大きい動画

## 公開前に設定するもの（`index.html` の先頭）
- `FEEDBACK_URL`：感想フォーム（Googleフォームなど）の URL。空なら非表示
- `GOATCOUNTER_CODE`：GoatCounter のコード名。空なら解析なし。記録する出来事：`1-動画を選んだ` `2-印をつけた` `3-書き出しを押した` `4-書き出せた` `x-高速方式が使えなかった` `x-録画も失敗` `x-書き出しが空だった` `a-自動で見つけた` `x-自動で見つからなかった` `x-自動判定できなかった`

## 確かめ方
Playwright の Chromium は H.264 を読めないので、VP9 入りの MP4 でテストする。`export.js` は ES モジュールなので `file://` ではなく `python3 -m http.server` などで開く。
```
ffmpeg -f lavfi -i testsrc2=size=1280x720:rate=30 -f lavfi -i sine=frequency=440:sample_rate=48000 \
  -t 20 -c:v libvpx-vp9 -b:v 1M -deadline realtime -cpu-used 8 -c:a libopus -shortest test.mp4
```
