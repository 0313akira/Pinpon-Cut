# ピンポンカット

卓球の試合動画を選び、ラリーの間だけ印をつけると、その区間だけをつないだ動画を書き出せるブラウザツール。サーバーなし・動画は端末から出ない・無料・登録不要。

## 使い方
1. `index.html` を開く（GitHub Pages で公開可）
2. 動画を選び、再生しながらラリーの区間に印をつける
3. 「書き出す」→ 保存

## 機能
- 操作方式は「押しっぱなし」か「タップで開始／終了」を選べる（スペースキー対応）
- バーのドラッグで区間を作る・端をドラッグで調整（取り消し可）
- Zで直前の操作を取り消し（履歴方式）／5秒戻る／1x・1.5x・2x
- 印の一覧、始め・終わりを今の位置に直す、削除、ラリーだけ連続再生、←→でラリー移動
- 印はブラウザに自動保存（「前回の続きから」）
- 書き出し：前後の余白を設定可。重なる区間は自動で結合

## 書き出しのしくみ（現状）
再生しながら MediaRecorder で録画する方式（ラリー合計と同じ時間がかかる）。
音は WebAudio 経由で録画に流すので、書き出し中に音は鳴らない。
