# ピンポンカット

卓球の試合動画から、ラリーの場面だけをつないだ動画を作るブラウザツール。サーバーなし・動画は端末から出ない・無料・登録不要。

## 使い方
1. ページを開いて動画を選ぶ
2. 再生しながら、ラリー中だけボタンを押す（押しっぱなし／タップ切替）。バーのドラッグでも作成・調整できる
3. 「書き出す」→ 保存（スマホは「写真に保存・共有」）

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` | 画面と操作（1️⃣ 動画を選ぶ → 2️⃣ 印をつける → 3️⃣ 書き出す の順） |
| `export.js` | 高速書き出し。書き出しを押したときだけ読み込む |
| `vendor/mediabunny-1.61.6.min.js` | MP4 の分解・組み立て部品（MPL-2.0, `vendor/mediabunny-LICENSE.txt`） |
| `privacy.html` | プライバシーポリシー |

## 書き出しのしくみ
1. **高速方式（通常）**：WebCodecs で必要なコマだけ読み取り→作り直し→MP4 に組み立て。再生しないので速い（60秒の動画で数秒）
   - 音は作り直さず元の音のかけらを並べる。区間の境目は音のかけらにそろえる → 音ズレなし
   - 映像の時刻は等間隔の格子に載せる（継ぎ目に短いコマを作らない）
   - 区間ごとに読み取り器を作り直す
   - 失敗時は診断文字列（どの段階・何本目・形式）をコンソールとエラー文に出す
2. **控え**：高速方式が使えないブラウザでは、再生しながら MediaRecorder で録画（実時間ぶんかかる）

## 公開前に設定するもの（`index.html` の先頭）
- `FEEDBACK_URL`：感想フォーム（Googleフォームなど）の URL。空なら非表示
- `GOATCOUNTER_CODE`：GoatCounter のコード名。空なら解析なし。記録する出来事：`1-動画を選んだ` `2-印をつけた` `3-書き出しを押した` `4-書き出せた` `x-高速方式が使えなかった` `x-録画も失敗` `x-書き出しが空だった`

## 確かめ方
Playwright の Chromium は H.264 を読めないので、VP9 入りの MP4 でテストする。`export.js` は ES モジュールなので `file://` ではなく `python3 -m http.server` などで開く。
```
ffmpeg -f lavfi -i testsrc2=size=1280x720:rate=30 -f lavfi -i sine=frequency=440:sample_rate=48000 \
  -t 20 -c:v libvpx-vp9 -b:v 1M -deadline realtime -cpu-used 8 -c:a libopus -shortest test.mp4
```
